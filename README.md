# FakeCard Generator 💳

A lightweight Python utility built with the `Faker` library to instantly generate dummy Mastercard numbers for local testing and web development validation.

## 🚀 Features
* Instant generation of 10 fake Mastercard numbers upon execution.
* Lightweight script with minimal dependencies.
* Clean console output optimized for testing form inputs and validation logic.

## 🛠️ Requirements
* Python 3.x
* `faker` library
